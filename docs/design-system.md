# PinPin 设计规范

## 材质

浮层采用不透明哑光灰面，光从左上来。可按控件凸起，按下、选中和输入区压入；不加装饰纹理。功能用低饱和图标色区分，文字与底板保持灰阶。

| 令牌 | 浅色 | 深色 |
| --- | --- | --- |
| surface | `#E5E5E8` | `#2C2C2F` |
| surfaceDeep | `#DCDCE0` | `#252528` |
| ink | `#1D1D1F` | `#ECECEF` |
| inkSecondary | `#48484D` | `#B6B6BB` |
| inkTertiary | `#606065` | `#949499` |

完整色值、增强对比度及自定义色转换以 `frontend/UITheme.swift` 为准。Windows 映射位于 `frontend/windows/PinPin.Presentation/Theme.cs`。

## 轮盘与结果

- 轮盘只显示图标；支持 1–8 格、空槽和重复功能。中心取消，移出可见圈后继续按角度选择。
- 结果按 ID 独立，收起为带功能图形的小球；悬停查看短卡，点击继续展开。卡片宽 320pt，正文 13pt，圆角 14pt；短卡最多三行，展开后保留完整正文。
- 小球轮廓为 0.8pt 功能同色边框。轮盘、小球和卡片的功能色来自同一份设置。
- 出现与消失采用短淡入淡出，不缩放弹跳；流式文字更新不重新显示窗口或重复执行入场动画。

## 设置

左侧是大轮盘，右侧是四列 42pt 小方块组成的功能库，支持多排滚动。从功能库拖入为复制；轮盘槽之间拖动为交换，拖出托盘清空，回中心取消。

点击功能进入独立详情页：宽 198pt，标题、单句说明和换色入口分层排列，间距 22pt。AI 标签由实际功能路径决定，取色器始终为本地功能。

换色默认收起，按需打开 240pt 宽的普通小窗口；208×140pt 饱和度/明度区域配色相滑条，显示 HEX 和恢复默认。连续拖动只预览，松手或关闭时保存最终值，不按像素写盘。关闭面板释放窗口和回调。

设置窗口可移动、可被其他窗口覆盖；左上单按钮切换明暗。触发开关仅控制轮盘手势，不影响设置快捷键。

## 文案与实现

常态界面只保留操作、内容和必要状态，不堆叠教程、成功提示或内部过程说明。错误保留可执行的恢复入口。字号、阴影、动效和键盘辅助以真实组件源码为准。

macOS 使用系统字体与 SF Symbols，嘴替使用两平台一致的原创线条大脑图标；Windows 使用系统字体和对应矢量绘制。图片预览展示 macOS 界面，不能据此推断 Windows 所有细节已一致。
